# 영어 쿼리도 (English Quoridor) — 교실용 2인 대전

영어 미션(5지선다 문제 또는 말하기)을 통과해야 말을 움직이거나 벽을 놓을 수 있는 쿼리도 게임입니다.
선생님이 방을 만들고 학생이 들어오면 **[게임 시작]** 한 번으로 2명씩 자동 매칭되고, 경기가 끝나면 자동으로 다음 상대와 계속 경기합니다.

## 실행 방법 (교사 컴퓨터)
1. Node.js 18 이상 설치 (https://nodejs.org → LTS)
2. 이 폴더에서 처음 한 번 `npm install`
3. `npm start`
4. 화면에 나오는 주소로 접속
   - 교사(이 컴퓨터): `http://localhost:3000`
   - 학생(태블릿): `https://교사PC의IP:3443` ← 말하기(마이크)를 쓰려면 반드시 https 주소
   - 교사 화면의 **▦ 버튼**을 누르면 학생 접속 QR 코드가 나옵니다.
5. 학생 태블릿에서 처음 https 주소에 들어가면 "안전하지 않음" 경고가 뜹니다. **고급 → 계속(안전하지 않음)** 을 한 번 누르면 됩니다. (학교 안에서만 쓰는 자체 보안 인증서라서 나오는 경고입니다.)

> 학생 기기와 교사 컴퓨터는 같은 와이파이에 있어야 하고, 처음 실행할 때 Windows 방화벽 허용 창이 나오면 "허용"을 눌러 주세요.
> 말하기 음성 인식은 크롬(Chrome) 브라우저의 음성 인식(인터넷 필요)을 사용합니다.

## 화면 구성 (디자인 시트 기반)
- 첫 화면: English Quoridor 타이틀 그림의 버튼(학생 게임 시작·교사용 관리·게임 방법·문제 미리보기·오늘의 순위·설정)
- 학생: 캐릭터 4종 중 선택 → 자동 매칭 대기 → 대전(정확한 9×9 판) → 결과(승리/패배 배지) → 최종 순위(시상대·메달)
- 교사: 나무 탭(전체 현황 · 실시간 관전 · 학생 기록 · 문제 관리 · 수업 종료) → 최종 순위·결과 다운로드
- 그림 파일: `public/assets/ui/` (디자인 시트에서 잘라낸 부품), `public/assets/title.jpg`

## 게임 규칙
- 9×9 원래 쿼리도 판, 각자 벽 10개, 아이템 없음
- 내 차례마다 영어 미션
  - **문제 풀기**: 5지선다. 맞히면 행동, 틀리면 정답을 보여 주고 차례가 넘어감
  - **말하기**: 보이는 문장을 읽으면 AI(음성 인식)가 성공/실패 판정. 기회 2번, 2번 모두 실패하면 차례가 넘어감
- 행동: 말 한 칸 이동(점프·대각선 규칙 포함) 또는 벽 놓기(길을 완전히 막는 벽은 불가)
- 맞은편 빨간 줄(상대 출발선)에 먼저 도착하면 승리 → 결과 화면 6초 → 자동으로 다음 상대
- 홀수 인원이면 1명은 AI 로봇과 대결
- 한 차례 제한 시간(기본 90초)이 지나면 차례가 넘어감
- 교사가 **게임 종료**를 누르면 총점(승 10점 + 무 5점 + 영어 미션 성공 1점)으로 최종 순위 확정

## 단원별 기본 문제 (10·11·12단원)
교과서 내용으로 만든 문제가 들어 있어요. 단원마다 5지선다 24문제 + 말하기 15문장.
- 10단원 I’d Like to Have the Fruit Salad — 음식 주문하고 맛 표현하기
- 11단원 Do You Know About Songpyeon? — 알고 있는지 묻고 답하기 · 권유하기
- 12단원 We Should Save the World — 의무 말하기 · 잊지 말아야 할 것 조언하기

**고르는 곳:** 방 만들기 창의 '문제 단원' 또는 교사 화면 [문제 관리] 탭(상단 '문제 단원' 칩을 눌러도 이동). 여러 단원을 함께 켜면 섞어서 나오고, 수업 중에 바꾸면 다음 문제부터 적용됩니다.
같은 문제를 엑셀로 보고 고칠 수 있게 `단원별_문제/` 폴더에 넣어 두었어요. 고친 파일을 [문제 관리]에서 올리면 '직접 올린 문제'로 바로 바뀝니다.

## 문제 올리기 (엑셀)
교사 화면 아래 **문제 은행 업로드**에서 샘플 양식을 내려받아 채운 뒤 올립니다. 말하기와 5지선다는 따로 보관됩니다.
- 말하기: `문장`, (선택) `뜻`
- 5지선다: `문제`, `보기1`~`보기5`, `정답`(1~5)

## 교사 기능
- 활동(말하기/문제 풀기)과 차례 시간은 수업 중에도 변경 가능
- 실시간 경기 관전(카드/목록), 전체 순위, 일시정지/다시 시작
- 말하기 인식 실패·학생 도움 요청 시 **말하기 통과 승인**
- 학생 관리(내보내기), 영어 학습 분석, 오답 분석
- **엑셀로 결과 저장**: 최종 순위 · 학습 분석 · 오답 분석 · 경기 기록 (4개 시트)
- 교사 화면을 새로고침하거나 브라우저를 껐다 켜도 같은 교실로 돌아옴
- 서버를 껐다 켜도 수업이 복원됨(일시정지 상태로 시작 → [다시 시작])

## 설정(선택)
| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `TEACHER_PIN` | 없음 | 지정하면 방 만들 때 PIN 필요 |
| `PORT` / `HTTPS_PORT` | 3000 / 3443 | 접속 포트 |
| `MAX_STUDENTS` | 30 | 한 교실 최대 인원 |
| `HTTPS=0` | — | https 서버 끄기 |

## 폴더
- `units.js` 10·11·12단원 기본 문제 · `server.js` 교실 서버 · `engine.js` 쿼리도 규칙 · `speech.js` 말하기 판정 · `questions.js` 문제/엑셀
- `public/` 화면(타이틀, 학생, 교사), `public/assets/` 게임 그림
- `tests/` 자동 테스트 (`npm test`)
- 실행 중 생기는 `state/`(수업 저장), `results/`(결과), `cert/`(보안 인증서)는 공유하지 마세요.
